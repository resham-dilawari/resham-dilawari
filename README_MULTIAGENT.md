## 🏗️ System Architecture

### Multi-Agent System Design

```
┌─────────────────────────────────────────────────────┐
│           🎭 Orchestrator Agent (Master)            │
│  - Coordinates all agents                           │
│  - Manages workflows                                │
│  - Synthesizes insights                             │
│  - Resolves conflicts                               │
└───────────────────┬─────────────────────────────────┘
                    │
        ┌───────────┴───────────┐
        │                       │
    Parallel              Sequential
   Execution             Dependencies
        │                       │
┌───────┴───────────────────────┴─────────┐
│                                         │
│  Specialized Agent Network:             │
│                                         │
│  🔍 Fundamental Analysis Agent          │
│     → Company financials & valuation    │
│                                         │
│  📈 Technical Analysis Agent            │
│     → Charts, patterns & momentum       │
│                                         │
│  📰 News Sentiment Agent                │
│     → News analysis & psychology        │
│                                         │
│  ⚠️ Risk Assessment Agent               │
│     → Portfolio risk & diversification  │
│                                         │
│  🎯 Portfolio Optimizer Agent           │
│     → Asset allocation & rebalancing    │
│                                         │
│  🔬 Market Research Agent               │
│     → Sector trends & opportunities     │
│                                         │
│  💰 Tax Optimization Agent              │
│     → Tax-efficient strategies          │
│                                         │
└─────────────────────────────────────────┘
```

### Key Design Principles

1. **Agent Specialization**: Each agent is an expert in one domain
2. **Autonomous Operation**: Agents work independently within their domain
3. **Collaborative Intelligence**: Orchestrator synthesizes multi-agent insights
4. **Parallel Execution**: Independent agents run concurrently for speed
5. **Conflict Resolution**: Orchestrator resolves disagreements between agents
6. **Explainable AI**: Full transparency into agent decision-making

## 📊 Agent Descriptions

### 1. 🎭 Orchestrator Agent (Master Coordinator)

**Role**: Central coordinator managing all specialized agents

**Capabilities**:
- Determines which agents to activate based on request
- Manages parallel vs sequential execution
- Synthesizes insights from multiple agents
- Resolves conflicting recommendations
- Provides final strategic decisions

**Why It Matters**: Demonstrates understanding of complex system orchestration and decision-making under uncertainty

---

### 2. 🔍 Fundamental Analysis Agent

## 🎯 How to Use

### Installation

```bash
# Clone the repository
git clone <repo-url>
cd "AI Portfolio Advisor"

# Install dependencies
pip install -r requirements.txt

# Set up environment variables
cp .env.example .env
# Edit .env and add your GEMINI_API_KEY
```

### Running the Application

```bash
# Run the multi-agent version
streamlit run app_multiagent.py

# Or run the simple version
streamlit run app.py
```

### Usage Flow

1. **Configure Your Profile**
   - Enter stock tickers (e.g., RELIANCE.NS, TCS.NS)
   - Specify investment corpus
   - Set risk tolerance
   - Define investment goals

2. **Select Analysis Mode**
   - Full Advisory: Complete multi-agent analysis
   - Portfolio Analysis Only: Analyze current holdings
   - Investment Suggestions Only: Get new recommendations

3. **Run Analysis**
   - Click "Run Multi-Agent Analysis"
   - Watch agents work in real-time
   - Review comprehensive reports

4. **Explore Results**
   - Executive Summary: High-level synthesis
   - Agent Insights: Individual agent analysis
   - Detailed Analysis: Raw data and metrics
   - Execution Log: Full transparency
